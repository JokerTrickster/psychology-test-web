## 1. Overview

기존 점수 기반 앵무새 심리테스트(10질문, 31마리 결과)에 추가로 "나랑 성격 궁합이 좋은 모란도란 앵무새는?" 테스트를 신규 개발한다.

### 1.1 핵심 요구사항
- 5단계(5개 질문), 2지선다(A/B) 방식
- 결과: 5마리 앵무새 (로또, 럭키, 짹슨, 마이클, 스타)
- 시작 화면에서 기존 테스트와 새 테스트 선택 가능
- 결과 페이지는 새로운 스타일로 차별화
- 질문 데이터와 결과 이미지는 사용자가 별도 전달

## 2. Requirements

### 2.1 기능 요구사항

| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| FR-01 | 테스트 선택 화면: 기존 테스트 / 새 테스트 선택 UI | Must |
| FR-02 | 5개 질문 순차 표시 (2지선다, A: +1 / B: -1 점수) | Must |
| FR-03 | 점수 기반 5마리 앵무새 결과 매칭 | Must |
| FR-04 | 새 결과 페이지 스타일 (기존과 차별화) | Must |
| FR-05 | 결과 이미지 표시 및 성격 설명 | Must |
| FR-06 | 다시하기 → 테스트 선택 화면으로 복귀 | Should |
| FR-07 | 진행바 표시 (현재/전체 질문) | Should |

### 2.2 비기능 요구사항

| ID | 요구사항 |
|----|----------|
| NFR-01 | 기존 테스트 기능에 영향 없음 (회귀 방지) |

| NFR-03 | 페이지 전환 애니메이션 유지 |

## 3. Scope

### 3.1 In Scope
- 테스트 선택 화면 (홈)
- 새 테스트용 데이터 구조 (JSON)
- 질문 페이지 (기존 컴포넌트 재사용 가능)
- 새로운 결과 페이지 스타일
- App 컴포넌트 라우팅 로직 변경

### 3.2 Out of Scope
- 기존 31마리 테스트 수정
- 백엔드/서버 연동
- 소셜 공유 기능
- 결과 저장 기능

## 4. Technical Approach

### 4.1 데이터 구조

5개 질문, 5개 결과의 점수 기반 시스템. 점수 범위:
- 5질문 × (±1) = 총 점수 범위 -5 ~ +5
- 5마리에 점수 구간 분배

```
점수 구간 예시:
-5 ~ -3: 앵무새 A
-2 ~ -1: 앵무새 B
 0:       앵무새 C
 1 ~  2: 앵무새 D
 3 ~  5: 앵무새 E
```

(실제 매핑은 사용자 제공 데이터에 따라 결정)

### 4.2 파일 구조 변경

```
src/
├── App-score.tsx          → 테스트 선택 로직 추가 (수정)
├── main.tsx               → 변경 없음
├── types-score.ts         → 기존 타입 재사용
├── scenario/
│   ├── score-data.json    → 기존 유지
│   └── parrot-data.json   → 새 테스트 데이터 (신규)
├── pages/
│   ├── TestSelectPage.tsx → 테스트 선택 화면 (신규)
│   ├── QuestionPage-score.tsx → 재사용
│   └── ResultPage-parrot.tsx  → 새 결과 페이지 스타일 (신규)
└── public/
    └── images/
        └── parrots/       → 새 앵무새 이미지 (신규)
```

### 4.3 상태 관리 흐름

```
TestSelectPage (선택)
  ├── 기존 테스트 → StartPage → QuestionPage → ResultPage
  └── 새 테스트 → QuestionPage → ResultPage-parrot
```

## 5. Risk Assessment

| 리스크 | 영향 | 대응 |
|--------|------|------|
| 데이터/이미지 미전달 시 개발 지연 | High | 플레이스홀더로 우선 구현, 데이터 수신 후 교체 |
| 새 결과 페이지 스타일 기준 모호 | Medium | 기존 스타일 기반 변형으로 시작, 피드백 반영 |
| 기존 테스트 회귀 | Medium | 기존 코드 최소 변경, 테스트 선택 레이어만 추가 |

- [ ] 시작 화면에서 두 테스트 선택 가능

- [ ] 5마리 앵무새 중 점수에 맞는 결과 표시
- [ ] 새 결과 페이지 스타일 적용
- [ ] 기존 테스트 정상 동작 유지
- [ ] 모바일 반응형 정상
