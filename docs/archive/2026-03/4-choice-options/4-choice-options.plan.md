## 1. 요구사항

### 1.1 대상 테스트 (점수 기반 5개)
| 파일 | 테스트명 | 질문 수 | 현재 결과 수 |
|------|----------|---------|-------------|
| `score-data.json` | 앵무새 성격 | 10 | 26 |
| `parrot-data.json` | 나와 닮은 앵무새 | 5 | 5 |
| `office-data.json` | 직장/학교 유형 | 5 | 5 |
| `job-data.json` | 어울리는 직업 | 5 | 5 |
| `mbti-data.json` | 연애 MBTI | 5 | 5 |

### 1.2 점수 체계 변경
- **기존**: 2지선 → `+1` / `-1`
- **변경**: 4지선 → `+2` / `+1` / `-1` / `-2`
- **점수 범위 변화**:
  - 5문항 테스트: -5~+5 → -10~+10
  - 10문항 테스트 (score-data): -10~+10 → -20~+20

### 1.3 선택지 성격
각 질문당 4개 선택지:
1. **강한 긍정** (+2): 해당 특성에 매우 해당
2. **약한 긍정** (+1): 해당 특성에 약간 해당
3. **약한 부정** (-1): 해당 특성에 약간 비해당
4. **강한 부정** (-2): 해당 특성에 매우 비해당

## 2. 변경 범위

### 2.1 타입 변경 (`types-score.ts`)
- `options: [ScoreOption, ScoreOption]` → `options: ScoreOption[]` (2~4개 유연 지원)
- `ScoreOption.score` 타입: `number` 유지 (이미 유연)

### 2.2 UI 변경 (`QuestionPage-score.tsx`)
- A/B 라벨 → A/B/C/D 라벨 (동적 생성)
- 모바일 하단 고정 영역: 2버튼 → 4버튼 레이아웃
- 버튼 패딩/크기 조정 (4개가 화면에 들어가도록)
- `birdColors` 배열: 2개 → 4개로 확장

### 2.3 데이터 변경 (5개 JSON 파일)
- 각 질문의 `options` 배열: 2개 → 4개 선택지
- 각 결과의 `scoreRange`: 새 점수 범위에 맞게 재조정
- 선택지 텍스트: 기존 2개 기반으로 중간 단계 2개 추가 작성

### 2.4 테스트 코드 변경
- `QuestionPage-score.test.tsx`: 4지선 렌더링 테스트
- `App-score.test.tsx`: 4지선 점수 합산 테스트

## 3. 구현 순서

## 4. scoreRange 재조정 전략

### 5문항 테스트 (parrot, office, job, mbti)
- 현재 범위: -5 ~ +5 (11단계)
- 새 범위: -10 ~ +10 (21단계)
- 결과 5개 → 범위를 균등 분할:
  - [-10, -5], [-4, -2], [-1, 1], [2, 4], [5, 10]

### 10문항 테스트 (score-data)
- 현재 범위: -15 ~ +15 (결과 26개, 대부분 1점 간격)
- 새 범위: -20 ~ +20 (41단계)
- 결과 26개 유지 → 범위를 비례적으로 2배 확장
